# which floats to latest on every build. This repo has been dormant since around
# April, so the next push would have pulled four months of drift across anthropic,
# supabase, pandas and yfinance in one rebuild — with no way to tell which one
# broke it. A sibling service went down exactly this way on 2026-08-16, when an
# unpinned dependency resolved to a new major that had removed a module the code
# imported.
#
# werkzeug is listed even though nothing imports it directly: flask 2.3.3 is a
# 2023 release whose own core dependency was floating free, so an upstream
# werkzeug could break the exact flask version pinned to stop things changing.
# Same hole was found and closed in the Valerius requirements.
#
# Versions mirror sp500-database-webapp, the sibling Flask app running the same
# libraries on the same platform, where they are verified in production.
# Remaining transitive deps are deliberately left floating — hand-pinning a
# partial tree is how requirements become unsolvable. A lockfile is the answer if
# this needs to go further.
